# ADR-001 — Flutter como framework

- Estado: aceptado (2026-11-10)
- Contexto: app Android/iOS mantenida por IA, dibujo 2D intensivo (techo, unifilar), offline-first.
- Decisión: Flutter + Dart 3, monorepo con paquetes; motor de cálculo en Dart puro.
- Consecuencias: un solo código; tipado fuerte; iOS requiere compilación en macOS (nube) en F8.
