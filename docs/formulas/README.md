# Fichas de fórmulas

Una ficha por fórmula del motor (`packages/solar_engine`), plan B.6. Se llenan desde F2.

Cada ficha (`NN-nombre.md`) contiene: ecuación, variables con **unidades SI**, fuente bibliográfica, supuestos/límites, caso de prueba con valores de referencia (de `tools/golden_data/`) y la ruta de la prueba que la valida.
